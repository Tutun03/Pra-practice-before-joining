Problem Statement:
You are tasked with managing a fleet of rental cars for a car rental service. You need to create two classes: Car and RentalService.

Car Class
Attributes:
carId – int
model – String
brand – String
dailyRent – double
isAvailable – boolean (true if the car is available for rent, false otherwise)
rentalCount – int (number of times the car has been rented)
Constructor:
Initialize all attributes.

Getters/Setters:
Provide getters and setters for all attributes.

RentalService Class
Attributes:
serviceName – String
customerCount – int (number of customers registered with the service)
cars – Array of Car objects
Constructor:
Initialize the service name, customer count, and the array of cars.

Solution Class
Method 1: findMostRentedCarInEachService(RentalService[] services)
Input Parameters:

An array of RentalService objects.
Returns:

Prints the most rented car for each service in the specified format.
Method 2: getCarsBelowDailyRent(RentalService[] services, double maxRent)
Input Parameters:

An array of RentalService objects.
A double representing the maximum daily rent.
Returns:

Prints all available cars across all services that have a daily rent below the given value.
Input Format
The input starts with the number of rental services.

For each service, input its attributes:

serviceName
customerCount
The number of cars in the fleet.
For each car, input its attributes:

carId, model, brand, dailyRent, isAvailable, and rentalCount.
Then, input the maximum daily rent to be passed to the getCarsBelowDailyRent method.

Output Format
For each service:
Print the service name.
Print the most rented car's details in the format:

carId, model, brand, dailyRent, isAvailable, rentalCount.
For cars below the given daily rent:
Print the details of each car in the format:

serviceName, carId, model, brand, dailyRent, isAvailable, rentalCount.
