Problem Statement:
You are tasked with managing a parking system in a city. You need to create two classes: Car and ParkingLot.

Car Class
Attributes:
carId – int
carNumber – String
ownerName – String
model – String
price – double
isParked – boolean (true if the car is parked, false if not)
hoursParked – int (how many hours the car has been parked)
Constructor:
Initialize all attributes.

Getters/Setters:
Provide getters and setters for all attributes.

ParkingLot Class
Attributes:
parkingLotName – String
capacity – int (maximum number of cars the parking lot can hold)
cars – Array of Car objects
Constructor:
Initialize the parking lot name, capacity, and the array of cars.

Solution Class
Method 1: findLongestParkedCarInEachParkingLot(ParkingLot[] parkingLots)
Input Parameters:

An array of ParkingLot objects.
Returns:

Prints the longest parked car for each parking lot in the specified format.
Method 2: getCarsBelowPrice(ParkingLot[] parkingLots, double maxPrice)
Input Parameters:

An array of ParkingLot objects.
A double representing the maximum price of the car.
Returns:

Prints all cars parked in all parking lots that are priced below the given max price.
Input Format
The input starts with the number of parking lots.

For each parking lot, input its attributes:

parkingLotName
capacity
The number of cars currently parked.
For each car, input its attributes:

carId, carNumber, ownerName, model, price, isParked, and hoursParked.
Then, input the maximum price to be passed to the getCarsBelowPrice method.

Output Format
For each parking lot:
Print the parking lot name.
Print the longest parked car's details in the format:

carId, carNumber, ownerName, model, price, isParked, hoursParked.
For cars below the given price:
Print the details of each car in the format:

parkingLotName, carId, carNumber, ownerName, model, price, isParked, hoursParked.
