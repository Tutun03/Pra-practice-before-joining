Create a class named Book with the following attributes:

id (int)
title (String)
author (String)
price (double)
The above attributes should be private, and the class should have a parameterized constructor to initialize them.

Implement the following methods in the Book class:

getPrice(): This method should return the price of the book.
getAuthor(): This method should return the author of the book.
Create a class named Library with the following attributes:

libraryName (String)
books (Book array)
numBooks (int)
The above attributes should be private, and the class should have a parameterized constructor to initialize them.

Implement the following methods in the Library class:

getTotalCost(): This method should return the total cost of all the books in the library.
getMostExpensiveBook(): This method should return the book with the highest price.
getBooksByAuthor(String author): This method should return an array of all books written by the given author.
In the main method, use a Scanner object to read the values of the library name, number of books, and the book details (id, title, author, and price) in a loop. Once all book details have been read, create a Library object and pass the appropriate parameters. Finally, call the three methods mentioned above and print the output.

Note: All searches should be case-insensitive.

Sample Input:

Enter number of books: 3  
Enter book details:  
Book 1:  
Enter id: 1  
Enter title: To Kill a Mockingbird  
Enter author: Harper Lee  
Enter price: 15.99  

Book 2:  
Enter id: 2  
Enter title: 1984  
Enter author: George Orwell  
Enter price: 12.50  

Book 3:  
Enter id: 3  
Enter title: Animal Farm  
Enter author: George Orwell  
Enter price: 9.99  
Sample Output:
