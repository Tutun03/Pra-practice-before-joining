Problem Statement:
You are tasked with managing a library's collection of books and the users who borrow them. You need to create two classes: Book and Library.

Book Class:
Attributes:

bookId – int
title – String
author – String
price – double
isAvailable – boolean (true if available, false if not)
borrowedCount – int (how many times the book has been borrowed)
Constructor: Initialize all attributes.

Getters/Setters: Provide getters and setters for all attributes.

Library Class:
Attributes:

libraryName – String
userCount – int (the number of users registered with the library)
books – Array of Book objects
Constructor: Initialize the library name, books, and user count.

Solution Class:

Method 1: findMostBorrowedBookFromEachLibrary(Library[] libraries)
Input Parameters:
An array of Library objects.
Returns: Prints the most borrowed book for each library.

Method 2: getBooksBelowPrice(Library[] libraries, double maxPrice)
Input Parameters:
An array of Library objects.
A double representing the maximum price.
Returns: Prints all available books across all libraries that are priced below the given maxPrice.

Input Format:
The input starts with the number of libraries.
For each library, input its attributes:
libraryName
userCount
The number of books.
For each book, input its attributes:
bookId, title, author, price, isAvailable, and borrowedCount.
Then input the maximum price to be passed to the getBooksBelowPrice method.

Output Format:
For each library:
Print the library name.
Print the most borrowed book's details in the format: bookId, title, author, price, isAvailable, borrowedCount.

For books below the given price:
Print the details of each book that meets the criteria in the format:
libraryName, bookId, title, author, price, isAvailable, borrowedCount.
